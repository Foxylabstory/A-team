# Загрузчик новостей Instagram

Это отдельный небольшой сервис для размещения там, где доступны Instagram и серверы
его фотографий. VPN на российском сервере сайта и у посетителей не нужен.
Сервис получает только публикации одного настроенного аккаунта. API заявок, база клуба,
имена и телефоны посетителей ему недоступны.
Apify не используется. Нужен собственный сервер загрузчика с доступом к Meta; плата
за его размещение зависит от выбранного хостинга. Уже работающий подходящий сервер
можно использовать без отдельного сервиса-парсера. GitHub Actions не требуется.

## Основной вариант: Instaloader, без Meta for Developers

`IG_SOURCE=instaloader` читает открытые публикации `antipov__team` собственным скриптом
на Instaloader 4.16. Приложение Meta, профессиональный аккаунт и ключ официального API
для этого режима не требуются. Сначала используется анонимный доступ. Проверка 3 ноября
2026 года прочитала 50 публикаций клуба и нашла четыре с #новости; сбор занял около трёх
минут. Это проверка с локального соединения, а не гарантия доступа с любого хостинга.

Установите Node.js 24.13+, Python 3.10+ и зависимости только на сервере загрузчика:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
# В .env: IG_SOURCE=instaloader, IG_PYTHON=/полный/путь/.venv/bin/python
# IG_NEWS_ACCOUNT=antipov__team, IG_NEWS_HASHTAG=новости
# NEWS_LOADER_TOKEN=случайный_секрет_длиной_не_меньше_32_символов
npm start
```

По умолчанию просматриваются 100 публикаций (`IG_SCAN_LIMIT`, от 1 до 500), затем
выбираются шесть самых свежих с точным тегом в подписи. Если совпадений меньше шести,
возвращаются найденные записи. При достижении лимита админка показывает, сколько
публикаций проверено. Порядок закреплённых записей не влияет на сортировку по дате.
Сайт показывает только три самые свежие видимые новости. Для них основной сервер
скачивает видео через защищённый маршрут загрузчика и хранит у себя. Для карусели
используется первый найденный ролик; остальные слайды не объединяются в фильм.
Посетитель смотрит локальный MP4 с управлением и перемоткой, без обращения к Instagram.
Ограничение одного ролика — 100 МиБ. Если скачивание не удалось, остаются текст и обложка,
а в админке появляется ошибка видео. Следующий импорт повторит попытку.
Когда новость выходит из показываемой тройки, скрывается или удаляется, её видео
удаляется с сервера клуба; текст и фотография сохраняются. Возвращённая в тройку
новость может скачать ролик заново, пока источник доступен. Загрузчик передаёт видео
потоком, не накапливая его на своём диске.

Сбор выполняется в отдельном процессе, до 15 минут. Загрузчик отвечает `202` во время
работы, а сайт опрашивает тот же адрес в фоне, не создавая повторных задач. Основному
серверу задайте `NEWS_ASYNC_IMPORT=true`: кнопка вернёт управление сразу, а результат
появится в админке после завершения. Страницу можно закрыть. При остановке основного
сервера ожидание отменяется, последняя сохранённая лента остаётся в базе.

Успешная подборка сохраняется в `private/instaloader-feed.json`. Обычные запросы
используют её в течение суток. Кнопка администратора передаёт `X-News-Refresh: 1` и
запускает обновление; повтор в первую минуту использует кеш. После ошибки повторный
сбор разрешён через час. Ошибка не выдаёт старый кеш за новый успешный результат.
`GET /health` используется только для проверки запуска и не начинает сбор.

Instaloader — неофициальный инструмент. Instagram может ограничить запросы, потребовать
вход или изменить формат данных. Скрипт не обходит CAPTCHA и не читает закрытые
аккаунты. Для работы следует поддерживать актуальную версию библиотеки.

Если Instagram потребует обычный вход, на доверенном компьютере/сервере с доступом
к Instagram выполните:

```bash
.venv/bin/python instaloader-news.py --login --session-file private/session.json
```

Скрипт попросит имя аккаунта, пароль и, при необходимости, код второго фактора.
Пароль не сохраняется. В закрытый JSON-файл записывается сессия: она даёт доступ к
аккаунту, поэтому её нельзя публиковать или присылать в чат. Скрипт не извлекает
cookies из браузера. Задайте `IG_SESSION_FILE=/закрытый/путь/session.json` и перезапустите
загрузчик. Файлы сессии не загружаются в Git и не включаются в Docker-образ.

Для пробного размещения подготовлены [Dockerfile](Dockerfile) и
[инструкции Railway](DEPLOY-RAILWAY.md) и [Render](DEPLOY-RENDER.md).
На российском сервере Python не требуется.

Документация: [Instaloader](https://instaloader.github.io/),
[ограничения и ошибки доступа](https://instaloader.github.io/troubleshooting.html).

## Необязательный вариант: официальный API Meta

Для `https://www.instagram.com/antipov__team/` требуется разрешение владельца аккаунта.
Одной публичной ссылки для официального API недостаточно.

1. Проверить в Instagram, что выбран профессиональный тип «Бизнес» или «Автор».
2. В [Meta for Developers](https://developers.facebook.com/apps/) зарегистрировать приложение
   для интеграции сайта и добавить Instagram API с Instagram Login. Это запись интеграции
   в кабинете Meta; скачивать мобильное приложение не требуется.
3. Подключить аккаунт `antipov__team` в настройках Instagram API и подтвердить разрешение
   на чтение основных данных и публикаций (`instagram_business_basic`). Для этого проекта
   не нужны права на переписку, управление комментариями или публикацию материалов.
4. В настройках API этого приложения выбрать **Generate token** рядом с подключённым
   аккаунтом, войти в Instagram и получить токен. Для своего аккаунта, добавленного в
   приложение, используется предусмотренный Meta доступ; возможность подключения
   сторонних аккаунтов может потребовать отдельного App Review.
5. Сохранить Instagram User ID и токен в закрытом `.env` загрузчика: `IG_USER_ID` и
   `IG_ACCESS_TOKEN`, вместе с `IG_LOGIN=instagram`. ID — числовой идентификатор API,
   а не имя `antipov__team`. Пароль Instagram загрузчику не нужен.

Токен из App Dashboard действует 60 дней. Его нужно своевременно продлевать по
официальной процедуре или заменять. Автоматическое продление токена этот сервис
не выполняет. При истёкшем или отозванном токене импорт останавливается; прежние
новости остаются на сайте, а в админке появляется сообщение об ошибке доступа.
Не помещайте токен в чат, репозиторий, адреса страниц сайта или браузерный код.

Пошаговая документация Meta:
[получение токена](https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-instagram-login/get-started),
[продление доступа](https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-instagram-login/business-login).

## Размещение

Скопируйте на отдельный сервер только эту папку `instagram-loader/`.
Не копируйте `.env`, `data/` и `backups/` основного сервера клуба.
Дополнительных npm-пакетов не требуется; нужен Node.js 24.13+.

```bash
cp .env.example .env
# Заполните .env
npm start
```

В `.env` задайте:

- `NEWS_LOADER_TOKEN` — случайный секрет не короче 32 символов; используйте, например,
  32 случайных байта в hex. Это отдельный секрет, не пароль администратора и не токен Meta.
- `IG_USER_ID` и `IG_ACCESS_TOKEN` — данные подключённого профессионального аккаунта клуба.
  Они нужны только при `IG_SOURCE=official`.
- `IG_LOGIN=facebook` для имеющегося подключения через Facebook или `instagram` для
  Instagram Login; токен должен соответствовать выбранному способу.
- `IG_API_VERSION=v25.0` — используемая версия API, её можно обновить через настройку.
- `IG_NEWS_HASHTAG=новости` — тег в ПОДПИСИ публикации. Регистр букв не важен.
- `IG_NEWS_ACCOUNT=antipov__team` — ожидаемое имя аккаунта; одинаковое на сайте и загрузчике.

Сервис по умолчанию слушает `127.0.0.1:3100`. Перед ним настройте nginx с HTTPS
на отдельном домене. Проксируйте `/news` и ограниченный маршрут видео, не включайте
кэширование, не записывайте заголовок Authorization в логи.

Пример location внутри уже настроенного HTTPS-сервера nginx:

```nginx
location = /news {
    proxy_pass http://127.0.0.1:3100;
    proxy_set_header Authorization $http_authorization;
    proxy_read_timeout 65s;
}
location ~ ^/videos/[0-9]{1,40}\.mp4$ {
    proxy_pass http://127.0.0.1:3100;
    proxy_set_header Authorization $http_authorization;
    proxy_buffering off;
    proxy_read_timeout 310s;
}
```

На основном сервере клуба задайте:

```dotenv
IG_NEWS_FEED_URL=https://ваш-домен-загрузчика/news
IG_NEWS_FEED_TOKEN=тот_же_секрет_что_NEWS_LOADER_TOKEN
IG_NEWS_HASHTAG=новости
IG_NEWS_ACCOUNT=antipov__team
NEWS_AUTO_UPDATE=true
NEWS_ASYNC_IMPORT=true
```

Перезапустите основной сервер. После подключения источника он выполняет первый импорт,
затем повторяет его раз в сутки. В `/admin/` → «Новости» также доступна кнопка
«Загрузить из Instagram». Для режима `official` подключение профессионального аккаунта
и выдача прав Meta выполняются отдельно. Режиму `instaloader` они не требуются.

## Что загружается

В режиме `official` при импорте просматриваются до 500 последних публикаций с переходом
по страницам API. Из совпавших по точному хештегу выбираются шесть самых свежих по дате.
Stories и комментарии не читаются. Для фото/карусели используется основное изображение,
для видео/Reels — обложка; сами видео не копируются.

Фотографии JPEG/PNG/WebP до 2 МБ загружаются в память сервиса и возвращаются вместе
с подборкой по защищённому запросу. Основной сервер сохраняет их у себя; посетители
получают изображения с домена клуба, без запросов к Meta. Адреса изображений допускаются
только с HTTPS-серверов `cdninstagram.com` и `fbcdn.net`; перенаправления не выполняются.
Если фото имеет другой формат/размер или недоступно, импорт завершается ошибкой,
сохранённая лента остаётся на месте. Уменьшите исходный материал или добавьте новость вручную.

В режиме `official` загрузчик не хранит подборку на диске; режим `instaloader` использует
закрытый суточный кеш, описанный выше. Расписание выполняется основным сервером клуба.
Внешнему загрузчику передаются только запросы на получение публикаций, без данных заявок.
Одновременно
выполняется один запрос; повторный запуск разрешён не чаще раза в минуту.
Текст и изображения могут содержать персональные данные участников клуба — разрешение
на их обработку и повторную публикацию должно соответствовать выбранной схеме.

При раскрытии общего секрета замените его на обеих сторонах и перезапустите оба сервиса.
Токен Meta также требует отдельного сопровождения и продления доступа.

Официальная документация использованного API:
https://developers.facebook.com/documentation/instagram-platform/instagram-graph-api/reference/ig-user/media
https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-instagram-login/get-started
