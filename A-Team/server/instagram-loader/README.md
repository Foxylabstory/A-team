# Загрузчик новостей Instagram

Это отдельный небольшой сервис для размещения там, где доступны официальный API Meta
и серверы фотографий Instagram. VPN на российском сервере сайта и у посетителей не нужен.
Сервис получает только публикации одного настроенного аккаунта. API заявок, база клуба,
имена и телефоны посетителей ему недоступны.

## Размещение

Скопируйте на отдельный сервер только эту папку `instagram-loader/`.
Не копируйте `.env`, `data/` и `backups/` основного сервера клуба.
Дополнительных npm-пакетов не требуется; нужен Node.js 24.13+.

```bash
cp .env.example .env
# Заполните .env
npm start
```

В `.env` задайте:

- `NEWS_LOADER_TOKEN` — случайный секрет не короче 32 символов; используйте, например,
  32 случайных байта в hex. Это отдельный секрет, не пароль администратора и не токен Meta.
- `IG_USER_ID` и `IG_ACCESS_TOKEN` — данные подключённого профессионального аккаунта клуба.
- `IG_LOGIN=facebook` для имеющегося подключения через Facebook или `instagram` для
  Instagram Login; токен должен соответствовать выбранному способу.
- `IG_API_VERSION=v25.0` — используемая версия API, её можно обновить через настройку.
- `IG_NEWS_HASHTAG=новости` — тег в ПОДПИСИ публикации. Регистр букв не важен.

Сервис по умолчанию слушает `127.0.0.1:3100`. Перед ним настройте nginx с HTTPS
на отдельном домене. Проксируйте только точный путь `/news`, не включайте кэширование,
не записывайте заголовок Authorization в логи, установите время ожидания ответа не менее 60 секунд.

Пример location внутри уже настроенного HTTPS-сервера nginx:

```nginx
location = /news {
    proxy_pass http://127.0.0.1:3100;
    proxy_set_header Authorization $http_authorization;
    proxy_read_timeout 65s;
}
```

На основном сервере клуба задайте:

```dotenv
IG_NEWS_FEED_URL=https://ваш-домен-загрузчика/news
IG_NEWS_FEED_TOKEN=тот_же_секрет_что_NEWS_LOADER_TOKEN
IG_NEWS_HASHTAG=новости
```

Перезапустите основной сервер. В `/admin/` → «Новости» станет доступна кнопка
«Загрузить из Instagram». Подключение профессионального аккаунта и выдача прав Meta
выполняются отдельно: расположение загрузчика не заменяет авторизацию.

## Что загружается

По явному запросу просматриваются до 500 последних публикаций аккаунта с переходом
по страницам API. Из совпавших по точному хештегу выбираются шесть самых свежих по дате.
Stories и комментарии не читаются. Для фото/карусели используется основное изображение,
для видео/Reels — обложка; сами видео не копируются.

Фотографии JPEG/PNG/WebP до 2 МБ загружаются в память сервиса и возвращаются вместе
с подборкой по защищённому запросу. Основной сервер сохраняет их у себя; посетители
получают изображения с домена клуба, без запросов к Meta. Адреса изображений допускаются
только с HTTPS-серверов `cdninstagram.com` и `fbcdn.net`; перенаправления не выполняются.
Если фото имеет другой формат/размер или недоступно, импорт завершается ошибкой,
сохранённая лента остаётся на месте. Уменьшите исходный материал или добавьте новость вручную.

Загрузчик не хранит подборку на диске и не импортирует по расписанию. Одновременно
выполняется один запрос; повторный запуск разрешён не чаще раза в минуту.
Текст и изображения могут содержать персональные данные участников клуба — разрешение
на их обработку и повторную публикацию должно соответствовать выбранной схеме.

При раскрытии общего секрета замените его на обеих сторонах и перезапустите оба сервиса.
Токен Meta также требует отдельного сопровождения и продления доступа.

Официальная документация использованного API:
https://developers.facebook.com/documentation/instagram-platform/instagram-graph-api/reference/ig-user/media
https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-instagram-login/get-started
