# Загрузчик на Railway

На Railway размещается только эта папка. Сайт клуба, база заявок, фотографии и
скачанные видео остаются на российском сервере. GitHub Actions не требуется:
Railway CLI может загрузить локальную папку без публикации репозитория.
Настройки ниже подготовлены, но сервис ещё не развёрнут. Доступ к Instagram
нужно проверить с выбранного региона Railway.

## Размещение

1. Войти в Railway и создать пустой проект (**New Project → Empty Project**).
2. Установить официальный Railway CLI и выполнить `railway login`.
3. Перейти именно в `A-Team/server/instagram-loader` и выполнить `railway link`,
   выбрав созданный проект, затем `railway up . --path-as-root`.
   `.railwayignore` разрешает отправить только код и файлы сборки: `.env`, кеш,
   сессии, база и материалы клуба исключены. Не запускайте загрузку из корня сайта.
4. В переменных сервиса задать:

| Переменная | Значение |
| --- | --- |
| `NEWS_LOADER_TOKEN` | Отдельный случайный общий секрет, минимум 32 символа |
| `IG_SOURCE` | `instaloader` |
| `IG_NEWS_ACCOUNT` | `antipov__team` |
| `IG_NEWS_HASHTAG` | `новости` |
| `IG_SCAN_LIMIT` | `50` для первой проверки; затем при необходимости увеличить |

Dockerfile задаёт Python и `HOST=0.0.0.0`. Railway передаёт порт через `PORT`.
При первой неудачной сборке из-за отсутствующей переменной задайте её и повторите
развёртывание. Ключ Apify и секреты основного сайта сюда не переносятся.

5. В **Settings → Networking → Public Networking** создать домен
   (**Generate Domain**) или выполнить `railway domain`. Указать проверку `/health`.
6. На российском сервере сайта задать:

```dotenv
IG_NEWS_FEED_URL=https://ваш-сервис.up.railway.app/news
IG_NEWS_FEED_TOKEN=тот_же_общий_секрет
IG_NEWS_ACCOUNT=antipov__team
IG_NEWS_HASHTAG=новости
NEWS_AUTO_UPDATE=true
NEWS_ASYNC_IMPORT=true
```

7. Перезапустить сайт и в админке запустить загрузку новостей. Первый сбор может
   занять несколько минут. Проверьте успешное завершение, локальные фотографии и
   проигрывание видео, если ролик есть среди трёх свежих записей. Сам `/health`
   проверяет запуск сервиса, а не доступ к Instagram.

Сайт инициирует сбор раз в сутки; отдельный Railway Cron не нужен. Кеш загрузчика
может потеряться при перезапуске — сохранённые на сервере клуба новости останутся.
Ролики передаются потоком, поэтому постоянный том для них на Railway не требуется.
Если источник потребует вход, отдельно настройте закрытую JSON-сессию по README;
не загружайте её вместе с исходным кодом.

## Стоимость и ограничения

Проверено по документации Railway 3 ноября 2026 года: Free включает $1 кредита
в месяц, пробный период — разовые $5 на 30 дней. Hobby стоит от $5 в месяц с
включёнными $5 использования; превышение оплачивается отдельно. Видео увеличивает
исходящий трафик. Бесплатного лимита нельзя заранее гарантировать для этой нагрузки.
Limited Trial ограничивает исходящую сеть; для проверки Instagram нужен подходящий
уровень доступа. Задайте доступный лимит расходов в кабинете.
